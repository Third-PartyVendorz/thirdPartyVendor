Services needed:
- ECR
    - 1 ECR repository
- ECS
    - 2 ECS task definitions
    - 2 ECS services
    - 1 ECS cluster
- RDS
    - 1 Db running Postgres 17
- S3
    - 2 buckets
- CloudFront
- Secrets Manager
- VPC

Jenkins Pipelines:

- Infrastructure Pipeline:
    - Plan and deploy AWS resources

- Build Pipeline:
    1. Set up environment
    2. Build and tag Spring API Docker image
    3. Push Docker image to ECR
    4. Render ECS task definition for Spring API
    5. Build and tag Flask API Docker image
    6. Push Docker image to ECR
    7. Render ECS task definition for Flask API
    8. Build static frontend files with ng build
    9. Push static files to S3 staging bucket

- Deploy Pipeline:
    1. Set up environment
    2. Pull docker image for Spring API from ECR
    3. Push image to ECS Spring task definition
    4. Pull docker image for Flask API from ECR
    5. Push image to ECS Flask task definition
    6. Pull static files from S3 staging bucket
    7. Push static files to live S3 bucket
    8. Invalidate previous CloudFront cache
